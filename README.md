# Backend (FastAPI) + Desktop App (PySide6)

## Architecture
```
PySide6 desktop app  --HTTP-->  FastAPI backend  -->  SQLite (persistent)
                                       |
                                       +--> XGBoost model + SHAP + dietary guidance
```

## Run the backend locally

```
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Visit http://127.0.0.1:8000/docs for interactive API documentation
(auto-generated by FastAPI) -- you can test every endpoint right in
the browser before connecting the desktop app.

## Run the desktop app locally

```
cd desktop_app
pip install -r requirements.txt
python main.py
```

By default it points at `http://127.0.0.1:8000` (your local backend).
Edit `BACKEND_URL` at the top of `main.py` once you deploy to Railway.

## Deploy the backend to Railway

1. Push the `backend/` folder to a GitHub repo (Railway deploys from Git).
2. In Railway: New Project -> Deploy from GitHub repo -> select the repo,
   set the root directory to `backend/` if your repo has other folders too.
3. Railway will detect the `Dockerfile` automatically and build from it.
4. Add a **Volume** in Railway (Settings -> Volumes), mount it at `/data`.
   This is what makes your SQLite data survive redeploys.
5. Set the environment variable `DB_PATH=/data/app.db` (already the
   Dockerfile's default, but confirm it's set in Railway's variables tab
   to match your volume mount path).
6. Railway automatically sets `$PORT` -- the Dockerfile's CMD already
   reads it, so no extra config needed there.
7. Once deployed, Railway gives you a public URL like
   `https://your-app.up.railway.app`. Update `BACKEND_URL` in
   `desktop_app/main.py` to that URL.

## API endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | /health | Health check |
| POST | /assess | Run a risk assessment, saves to history |
| GET | /assessments | List past assessments |
| GET | /assessments/{id} | Get one past assessment |
| GET | /scenarios | 5 pre-computed usability-eval scenarios |
| POST | /usability-review | Submit a reviewer's rating |
| GET | /usability-reviews | List all submitted reviews |
| GET | /usability-summary | Average ratings across all reviews |
